# About Armelito Aven (personal portfolio)

Plain HTML, CSS and JavaScript. No build step.

## Files
`index.html` Home, `about.html` About, `projects.html` Projects & Certificates, `contact.html` Contact, `style.css`, `script.js`, `assets/profile.jpg`.

## Deploy on GitHub Pages
1. On https://github.com/aevengaming20-create click **New repository**. Name it `aevengaming20-create.github.io` (site opens at `https://aevengaming20-create.github.io/`) or any name such as `portfolio` (site opens at `https://aevengaming20-create.github.io/portfolio/`). Make it **Public**.
2. Click **uploading an existing file**, drag in everything from this folder (keep the `assets` folder), then **Commit changes**.
3. Go to **Settings > Pages**. Under **Build and deployment** choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
4. Wait 1 to 2 minutes and open the URL shown at the top of the Pages screen.

## Contact form
The form opens the visitor's mail app addressed to the email set in `CONTACT_EMAIL` in `script.js`.

## Maintenance plan
- **New project:** copy an `<article class="card" data-type="project">` block in `projects.html` and edit the text.
- **New certificate:** copy a `data-type="cert"` card in `projects.html`, add the image to `assets/` and edit the text.
- **New achievement or skill:** edit the Achievements or Skills panel in `about.html`.
- **Update on GitHub:** open the file, click the pencil icon, edit, then **Commit changes**. The site refreshes in about a minute.
- Review the whole site once a month and after every semester: check links, dates and photos.
